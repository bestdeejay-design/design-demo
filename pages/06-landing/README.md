# Landing Page

Полноценный продающий лендинг SaaS-платформы «Orbita»: sticky-навбар с мобильным бургером, hero с CSS-моком продукта, полоса логотипов, анимированные счётчики статистики, сетка возможностей, этапы работы, отзывы, тизер тарифов, финальный CTA и футер.

## Возможности
- ✅ Sticky-навбар: логотип, якорные ссылки, CTA, бургер с aria-expanded на мобильных
- ✅ Hero-секция с двумя кнопками и CSS-дrawn моком дашборда (окно браузера, сайдбар, карточки, бар-чарт, список задач, плавающий тост)
- ✅ Полоса логотипов компаний (SVG-иконки, hover-эффект)
- ✅ Анимированные счётчики статистики при скролле (IntersectionObserver, 12 500+, 42, 99,9%, 97%)
- ✅ Сетка из 6 карточек возможностей с SVG-иконками
- ✅ «Как это работает» — 3 шага с соединительной линией
- ✅ Отзывы, тизер тарифов со ссылкой на страницу тарифов, финальный CTA с градиентом
- ✅ Футер с колонками ссылок
- ✅ Light/dark theme, адаптив, self-contained HTML/CSS/JS

## Когда применять
- Стартовый экран SaaS-продукта, стартапа или сервиса перед страницей тарифов
- Когда нужно показать ценность продукта, соцдоказательство и подтолкнуть к регистрации
- Как референс структуры лендинга: nav → hero → logos → stats → features → steps → reviews → pricing → CTA → footer
