# Badge & Tag

5 цветов (solid/soft), 3 размера, outline, with icon/dot, removable chips, notification badges (number/dot, sm/md/lg).

## Возможности
- Self-contained — один HTML файл с встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных

## Когда использовать
Стандартный набор Badge & Tag для типичных UI-сценариев.
