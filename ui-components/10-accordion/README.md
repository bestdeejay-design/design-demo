# Accordion

Single/multi expand, FAQ с иконками, flush, bordered варианты. CSS-анимация max-height, chevron rotate. С числами, meta, иконками.

## Возможности
- Self-contained — один HTML файл с встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных

## Когда использовать
Стандартный набор Accordion для типичных UI-сценариев.
