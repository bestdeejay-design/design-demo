# Cosmic System

Интерактивная 3D-сцена с солнечной системой: орбиты, планеты с физически вдохновлёнными параметрами, параллакс-звёздное поле, warp-эффект и туманности. Клик по планете — фокус с информационной карточкой.

## Возможности

- ✅ **Звёздное поле** на `<canvas>` — 420 звёзд в 3 слоях глубины с параллаксом по мышке
- ✅ **Мерцание звёзд** — каждая звезда пульсирует с уникальной фазой/частотой
- ✅ **Shooting stars** — периодически пролетают по сцене
- ✅ **Туманности** — CSS-градиенты с blur (4 цветовых пятна)
- ✅ **6 планет**: Меркурий, Венера, Земля, Марс, Юпитер, Сатурн (с кольцами)
- ✅ **Реалистичные орбиты** — периоды пропорциональны (Меркурий 8с, Сатурн 75с)
- ✅ **Клик по планете** — плавный зум камеры + info-карточка с типом, описанием и статистикой
- ✅ **Warp Speed** — кнопка (или `Space`/`W`) растягивает звёзды в стрики на 2.2с
- ✅ **HUD** — название сцены, координаты сектора, счётчик звёзд, FPS
- ✅ **Параллакс по мышке** — двигаешь мышь, туманности и звёзды слегка смещаются с разной скоростью
- ✅ **Просмотр кода** — встроенная панель с копированием (как в остальных компонентах)
- ✅ **Кнопка назад** — единый паттерн каталога
- ✅ **Адаптив** — на мобилке info-панель прибивается ко дну, кнопки уменьшаются
- ✅ **Клавиатура** — `Esc` сбрасывает фокус, `Space`/`W` — warp

## Когда использовать

- **Загрузочные экраны** для «тяжёлых» приложений / дашбордов — не скучный спиннер, а маленькое космическое путешествие
- **Hero-секции** для продуктов в сфере AI, sci-fi, gaming, exploration
- **Демо-обложки** для портфолио / pitch deck
- **«Mode selector»** — каждый уровень = своя планета, клик раскрывает функционал
- **Reward screen** — после достижения показываешь систему, в которой пользователь «заработал» планету
- **Loading state для 3D-идей** — анимированный preview будущего интерфейса

## Технологии

- Чистый HTML/CSS/JS (один файл, ~700 строк)
- Никаких зависимостей
- Canvas 2D для звёздного поля (перформанс)
- CSS-анимации для орбит и пульсации солнца
- CSS-переменные для единообразия с остальным каталогом
- `requestAnimationFrame` для плавного 60fps loop
- DPR-aware canvas для retina-чёткости
