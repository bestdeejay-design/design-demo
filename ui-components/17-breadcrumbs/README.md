# Breadcrumbs & Progress Stepper

Хлебные крошки: chevron (интерактивная навигация), 4 варианта разделителей (chevron/slash/dot/arrow), сворачиваемый длинный путь через «…». Прогресс-степперы: горизонтальный checkout (Корзина → Доставка → Оплата → Готово) с реальными данными заказа и вертикальный трекинг доставки с этапами и временем.

## Возможности
- Self-contained — один HTML файл со встроенными стилями и JS
- Light/dark theme с переключателем
- View Code кнопка с копированием
- Адаптив для мобильных
- Крошки и степперы полностью интерактивны, aria-current на текущем уровне

## Когда использовать
Навигация по иерархии (каталоги, документы), многошаговые формы (checkout, онбординг), трекинг заказов и статусов.
