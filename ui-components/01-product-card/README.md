# Product Card

Карточка товара для интернет-магазина.

## Особенности
- Изображение товара с ховер-эффектом
- Название, цена, рейтинг
- Кнопка добавления в корзину
- Адаптивная вёрстка

## Когда использовать
- Каталог товаров
- Список предложений
- Результаты поиска

## Референсы
- Dribbble: product card design
- Apple Store карточки товаров
