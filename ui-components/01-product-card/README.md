# Product Card

Интерактивная карточка товара для интернет-магазина.

## Возможности
- ✅ Избранное (❤️) — toggle с анимацией
- ✅ Выбор цвета (5 вариантов) — обновляет превью
- ✅ Выбор размера (S/M/L) — активный выделен
- ✅ Корзина — добавление с тостом и счётчиком
- ✅ Исходный код — встроенный просмотрщик с кнопкой Copy
- ✅ Адаптивная вёрстка

## Когда использовать
- Каталог товаров, список предложений, результаты поиска

## Технологии
- Чистый HTML/CSS/JS (один файл)
- Никаких зависимостей
