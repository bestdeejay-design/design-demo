# Tooltip

4 направления, light/dark, rich content (title+description), inline в тексте, на иконках. Hover на десктопе, tap на тач-устройствах (auto-detect).

## Возможности
- Self-contained — один HTML файл с встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных

## Когда использовать
Стандартный набор Tooltip для типичных UI-сценариев.
