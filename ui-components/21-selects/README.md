# Selects

Кастомные выпадающие списки: одиночный выбор с группировкой по регионам и поиском, множественный выбор с чипсами, счётчиком и кнопкой «Очистить».

## Возможности
- Одиночный селект: группы (регионы), поиск фильтрует города, пустые группы скрываются
- Мультиселект: чекбоксы, чипсы с удалением, счётчик «Выбрано: N», кнопка «Очистить»
- Закрытие по клику вне и по Esc
- Клавиатура: ArrowUp/ArrowDown по опциям, Enter выбирает
- Фокус-кольца (focus-visible) на триггерах, опциях и чипсах
- Self-contained — один HTML-файл, light/dark theme, View Code

## Когда использовать
Формы, фильтры, настройки профиля — везде, где нужен выбор одного или нескольких значений из длинного списка.
