# Search Bar

Default/filled/с кнопкой, 3 размера, ⌘K shortcut, clear-button, autocomplete с recent+popular, фильтрация с highlight совпадений, click-outside-close.

## Возможности
- Self-contained — один HTML файл с встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных

## Когда использовать
Стандартный набор Search Bar для типичных UI-сценариев.
