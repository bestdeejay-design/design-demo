# Context Menu

Кастомное контекстное меню: открывается правым кликом в позиции курсора (с клампингом к границам окна) или кнопкой с тремя точками. Полная поддержка клавиатуры, SVG-иконки, разделители и недоступный пункт.

## Возможности
- preventDefault на contextmenu, меню открывается у курсора и не выходит за вьюпорт
- Клавиатура: ArrowUp/ArrowDown циклически переходят по пунктам (пропуская разделители и disabled), Enter активирует, Esc закрывает и возвращает фокус
- Иконки Feather (edit, copy, scissors, trash, settings), один disabled-пункт, разделители
- Кнопка «⋯» в тулбаре открывает то же меню
- Строка статуса «Выполнено: <пункт>» при выборе действия
- Закрытие по клику вне меню
- Self-contained — один HTML-файл, light/dark theme, View Code

## Когда использовать
Файловые менеджеры, редакторы, таблицы и любые места, где нужны действия по правому клику или кнопке «ещё».
