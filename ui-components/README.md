# UI Components

Раздел с переиспользуемыми UI-компонентами: карточки, навигация, формы, профили и т.д.

## Цель раздела

Дать дизайнерам и разработчикам живые, интерактивные примеры компонентов, которые можно:
- Посмотреть в работе (кликнуть, потрогать)
- Скопировать исходный код
- Адаптировать под свой проект

## План развития

### Фаза 1 — Базовые компоненты (текущая)
- [x] Product Card — карточка товара (избранное, корзина, выбор размера)
- [x] Profile Card — карточка профиля (follow/unfollow, табы)
- [x] Navigation — адаптивная навигация (active-link, mobile menu, dropdown)

### Фаза 2 — Расширение (ближайшие)
- [ ] Form Elements — кастомные инпуты, селекты, чекбоксы, toggle
- [ ] Modal / Dialog — модальные окна, confirm, alert
- [ ] Tabs — горизонтальные и вертикальные табы
- [ ] Accordion / Collapse — раскрывающиеся секции
- [ ] Badge / Tag — чипсы, бейджи, статусы
- [ ] Skeleton / Loading — состояния загрузки
- [ ] Toast / Notification — уведомления

### Фаза 3 — Продвинутое
- [ ] Drag & Drop — сортируемые списки
- [ ] Infinite Scroll — лента с подгрузкой
- [ ] Advanced Tables — таблицы с сортировкой, фильтрацией
- [ ] Date Picker / Calendar
- [ ] Autocomplete / Search with suggestions

## Формат каждого примера

```
ui-components/N-название/
├── index.html     # Живая демка с интерактивом и отображением кода
├── README.md      # Описание, когда использовать, ссылки на референсы
└── (assets)       # Изображения, иконки при необходимости
```

## Принципы

1. Каждый компонент — **полностью рабочий**: кликабельный, с состояниями, без dead-зон
2. Исходный код **виден рядом** с демкой (встроенный просмотрщик)
3. Компоненты **адаптивны** (mobile-first)
4. Минимум зависимостей — чистый HTML/CSS/JS
5. Единая стилистика — современная, светлая/тёмная тема
