# Toast & Notification

Универсальная библиотека тостов: 4 типа, 6 позиций, экшены, стек, прогресс-бар auto-dismiss, инлайн-алерты и баннеры.

## Возможности
- ✅ **4 типа** — success / error / warning / info
- ✅ **6 позиций** — top/bottom × left/center/right
- ✅ **Auto-dismiss** — настраиваемый таймер с прогресс-баром
- ✅ **Action button** — кнопка внутри тоста (Отменить, Открыть, Повторить)
- ✅ **Stacking** — несколько тостов в очереди
- ✅ **Программный API** — `toast('success', 'msg', { position, duration, action })`
- ✅ **Inline Alerts** — в потоке контента, не исчезают
- ✅ **Banner** — sticky-полоса для важных объявлений

## Программный API
```js
toast('success', 'Файл сохранён');
toast('error', 'Не удалось подключиться', { duration: 0 }); // без авто-закрытия
toast('info', 'Элемент удалён', {
  action: { label: 'Отменить', onClick: () => console.log('undo') }
});
```

## Когда использовать
- Подтверждение успешного действия (сохранено, отправлено, оплачено)
- Ошибки валидации или сети
- Информационные подсказки
- Стек уведомлений в реальном времени
