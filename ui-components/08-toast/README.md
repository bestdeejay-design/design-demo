# Toast & Notification

4 типа × 6 позиций, auto-dismiss с прогресс-баром, action button, programmatic API, стек до 5+ тостов, inline alerts, banner.

## Возможности
- Self-contained — один HTML файл с встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных

## Когда использовать
Стандартный набор Toast & Notification для типичных UI-сценариев.
