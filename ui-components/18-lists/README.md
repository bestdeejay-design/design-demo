# List Group

Шесть типов списков: simple (настройки с выделением), icon (навигация с бейджами), avatar (команда со статусами и подписками), media & two-line (лента уведомлений с превью), checkbox (задачи с select-all, indeterminate и завершением), draggable (приоритеты спринта на нативном HTML5 drag-and-drop с пересчётом порядка).

## Возможности
- Self-contained — один HTML файл со встроенными стилями и JS
- Light/dark theme с переключателем
- View Code кнопка с копированием
- Адаптив для мобильных
- Кастомные чекбоксы с focus-visible, drag-and-drop без зависимостей

## Когда использовать
Меню и навигация, списки контактов и команд, ленты уведомлений, задачи с выбором, сортируемые приоритеты.
