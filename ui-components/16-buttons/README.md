# Buttons — Button Kit

Набор кнопок: 6 вариантов (Primary, Secondary, Outline, Ghost, Danger, Link), 4 размера + full-width, кнопки с иконками (leading/trailing/icon-only/round FAB), состояния (hover, focus, active, disabled, loading, success) и интерактивные сценарии: лайк с счётчиком, избранное, счётчик голосов, двойное подтверждение удаления.

## Возможности
- Self-contained — один HTML файл со встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных
- Keyboard accessible: focus-visible, aria-label на icon-only кнопках, aria-pressed на toggle

## Когда использовать
Стандартный набор кнопок для типичных UI-сценариев: формы, корзины, подтверждения, лайки.
