# Avatar

6 размеров, 7 цветовых пресетов, статусы (online с pulse, away, busy, offline), нотификации, group/stack с +N, формы (circle/rounded/square), outline.

## Возможности
- Self-contained — один HTML файл с встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных

## Когда использовать
Стандартный набор Avatar для типичных UI-сценариев.
