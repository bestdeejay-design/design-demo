# Navigation

Адаптивная навигация / хедер для сайта или приложения.

## Возможности
- ✅ Активные ссылки — переключение по клику + IntersectionObserver при скролле
- ✅ Dropdown «Products» — hover на десктопе, tap на мобилке
- ✅ Mobile menu — плавная анимация с затемнением
- ✅ Секции страницы — (Home, Products, Pricing, About, Contact) со скроллом
- ✅ Исходный код — встроенный просмотрщик с кнопкой Copy
- ✅ Glassmorphism — backdrop-filter: blur
- ✅ Адаптивная вёрстка

## Когда использовать
- Сайты и приложения, админ-панели, лендинги

## Технологии
- Чистый HTML/CSS/JS (один файл)
- Никаких зависимостей
