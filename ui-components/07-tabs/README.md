# Tabs

5 вариантов табов для разных сценариев — от горизонтальных до мобильного bottom bar.

## Возможности
- ✅ **Underline** — классика с анимированным подчёркиванием, scrollable на мобиле
- ✅ **Pills** — для фильтров, со счётчиками
- ✅ **Bordered** — заполняют всю ширину, для view-switcher'ов (День/Неделя/Месяц)
- ✅ **Vertical** — для sidebar-навигации в настройках
- ✅ **Mobile Bottom Bar** — стандарт для мобильных приложений, до 5 табов
- ✅ **Бейджи и счётчики** — встроены в табы
- ✅ **Клавиатура** — стрелки ←/→, Home/End для underline табов
- ✅ **Анимации** — fade-in панелей, плавное подчёркивание

## Когда использовать
- **Underline** — основной паттерн для навигации между секциями
- **Pills** — фильтры, view-switcher, сортировка
- **Bordered** — переключение между временными диапазонами или режимами
- **Vertical** — настройки, документация со множеством разделов
- **Mobile Bottom Bar** — основная навигация мобильного приложения

## Особенности реализации
- Активная вкладка определяется через `.is-active` класс
- Контент-панели скрываются/показываются через `hidden` атрибут
- Scope — панели ищутся в пределах своего `.section`
- `data-tab` / `data-tab-content` атрибуты для связи
