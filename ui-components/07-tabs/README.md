# Tabs

Underline (с анимированным подчёркиванием, scrollable, keyboard nav), Pill (с counts), Bordered (full-width), Vertical (sidebar), Mobile Bottom Bar (до 5 табов с badge).

## Возможности
- Self-contained — один HTML файл с встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных

## Когда использовать
Стандартный набор Tabs для типичных UI-сценариев.
