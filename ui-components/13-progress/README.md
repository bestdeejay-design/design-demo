# Progress

Все варианты progress-индикаторов: linear (5 цветов, 3 размера, indeterminate, striped), circular, stepper, spinner. С интерактивом (click bar = animate, stepper с prev/next).

## Возможности
- Self-contained — один HTML файл с встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных

## Когда использовать
Стандартный набор Progress для типичных UI-сценариев.
