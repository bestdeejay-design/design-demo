# Data Table

Сортируемая таблица товаров: клик по заголовку переключает направление сортировки (SVG-стрелка-индикатор), живой текстовый фильтр, выбор строк чекбоксами, пагинация по 8 строк, статусные бейджи наличия, липкая шапка и пустое состояние с кнопкой сброса.

## Возможности
- Сортировка по всем колонкам (asc/desc) с индикатором-стрелкой и aria-sort
- Живой фильтр по названию и категории
- Выбор строк: чекбокс в строке, «выбрать все» на странице, счётчик выбранных
- Пагинация: prev/next + номера страниц, 8 строк на страницу
- Статусные бейджи: В наличии / Заканчивается / Нет в наличии / В пути
- Липкая шапка таблицы (position: sticky)
- Пустое состояние «Ничего не найдено» с кнопкой сброса фильтра
- Self-contained — один HTML файл, light/dark theme, View Code

## Когда использовать
Каталоги товаров, админ-панели, списки заказов и любые таблицы с большим количеством строк, где нужны сортировка, фильтр и пагинация.
