# Profile Card

Интерактивная карточка профиля пользователя.

## Возможности
- ✅ Follow / Unfollow — переключение с обновлением счётчика
- ✅ Сообщение — inline-попап с textarea и отправкой
- ✅ Табы — Projects / Likes / About с переключением контента
- ✅ Исходный код — встроенный просмотрщик с кнопкой Copy
- ✅ Адаптивная вёрстка

## Когда использовать
- Социальные сети, команда проекта, комментарии, отзывы

## Технологии
- Чистый HTML/CSS/JS (один файл)
- Никаких зависимостей
