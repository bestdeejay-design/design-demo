# Profile Card

Карточка пользователя / профиля.

## Особенности
- Аватар с онлайн-статусом
- Статистика (подписчики, проекты)
- Кнопка подписки
- Плавные ховеры

## Когда использовать
- Социальные сети
- Команда проекта
- Комментарии / отзывы

## Референсы
- Twitter / X профили
- Dribbble player cards
