# Skeleton Loader

Card/user/article/table skeletons с shimmer-анимацией. Реальные карточки рядом для сравнения. Кастомизация через CSS (цвета, размеры, no-anim).

## Возможности
- Self-contained — один HTML файл с встроенными стилями и JS
- Light/dark theme с автоопределением системы
- View Code кнопка с копированием
- Адаптив для мобильных

## Когда использовать
Стандартный набор Skeleton Loader для типичных UI-сценариев.
