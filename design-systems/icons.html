Iconography

Иконки Feather — 287 штук, stroke-based, сетка 24×24, скруглённые окончания. Наследуют текущий цвет через currentColor и адаптируются к теме автоматически.

02

Библиотека иконок

05

Правила

Шесть принципов, которые держат иконки консистентными.

currentColor

SVG наследует цвет из CSS-контекста через stroke="currentColor". Не зашивайте hex внутри иконок.

Сетка 24×24

Все иконки рисуются на сетке 24×24 с viewBox="0 0 24 24". Масштабируйте через width/height, не через viewBox.

aria-hidden

Декоративные иконки помечайте aria-hidden="true". Текстовую пару даёт соседний элемент, не иконка.

Названия

Используйте семантические имена Feather (trash-2, check-circle) — они описывают действие, а не картинку.

Толщина штриха

stroke-width="2" для стандартных иконок. Для мелких 16px допустимо 1.75, чтобы штрих не «жирел».

Тема

В тёмной теме иконки автоматически меняют цвет через CSS-переменные — никаких дополнительных стилей не нужно.
