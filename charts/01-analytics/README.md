# Analytics — SVG-чарты

Страница аналитики с графиками, нарисованными вручную на inline SVG: без внешних библиотек.

## Возможности
- Line/area chart с анимацией отрисовки при загрузке и hover-тултипом
- Bar chart с тултипами и анимацией роста столбцов
- Donut chart с легендой и подсветкой сегментов
- Переключатель периода 7 дней / 30 дней / 90 дней — данные и KPI пересчитываются с переходом
- 4 KPI-карточки с дельтами (SVG-стрелки) относительно предыдущего периода
- Light/dark theme, адаптив, self-contained HTML/CSS/JS

## Когда использовать
Как референс для аналитических дашбордов без chart-библиотек: данные генерируются на лету (seeded PRNG), поэтому файл остаётся компактным.
