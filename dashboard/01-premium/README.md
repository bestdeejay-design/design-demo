# Premium Dashboard

Премиальный каркас рабочего пространства CRM: сайдбар, топбар и сетка виджетов.

## Возможности
- Sidebar: логотип, навигация с SVG-иконками, active-состояние, badge-счётчики, сворачивание до иконок
- Topbar: поиск, колокол уведомлений с dropdown (отметить прочитанным), меню пользователя
- Виджеты: sparkline-карточки, прогресс-бары проектов (обновление), список задач с чекбоксами (добавление), лента активности (обновление), donut по статусам задач
- Dropdown закрываются по клику вне и по Escape
- На мобильных сайдбар превращается в overlay, в топбаре появляется burger
- Light/dark theme, self-contained HTML/CSS/JS

## Когда использовать

Как отправная точка для премиальных продуктовых дашбордов: плотная сетка виджетов, мягкие тени, акцент #6c5ce7.
